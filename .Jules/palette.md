## 2024-05-23 - [Enabled Next Buttons for Better Feedback]
**Learning:** Users often feel lost when a "Next" button is disabled without explanation. Keeping the button enabled and showing a toast error upon click provides immediate, actionable feedback.
**Action:** When designing wizards or multi-step forms, default to enabled navigation buttons that trigger validation checks and user feedback (e.g., toasts) rather than silently disabling interaction.
